# Feedback to issues

Show a decision for every item: **parent-bound** (curriculum, content, Senzing facts, parent-owned
behavior) or **local** (Codex packaging, hooks, lifecycle, host interaction, validation, release).
Explain the decision and hand parent-bound items to `/escalate-to-parent`. Search duplicates and
file only local issues from this workflow; it never writes to another repository.
